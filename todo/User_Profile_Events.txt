Problem Statement

FEED_MESSAGE_TYPE_USER_PROFILE_UPDATED is not going to fly on the web client. Having the website refresh all data points is going to be too jarring for the user every time a user update is detected.

Solution

Add a payload/event_data to the FEED_MESSAGE_TYPE_USER_PROFILE_UPDATED feed message content.
